# Ecommerce-EurekaServer
Eureka Server for Ecommerce Application

## Services
1. [UserManagementService](https://github.com/aniketasalkar/Ecommerce-UserManagement-Service)
   - Manages user information, registration, and profile updates.
2. [AuthenticationService](https://github.com/aniketasalkar/Ecommerce-AuthenticationService)
   - Handles user authentication, login, and security.
3. [ProductCatalogService](https://github.com/aniketasalkar/Ecommerce-ProductCatalog-Service)
   - Manages the product catalog, including product details and categories.
4. [OrderManagementService](https://github.com/aniketasalkar/Ecommerce-OrderManagementService)
   - Processes and tracks customer orders.
5. [CartAndCheckoutService](https://github.com/aniketasalkar/Ecommerce-CartAndCheckout)
   - Manages the shopping cart and checkout process.
6. [NotificationService](https://github.com/aniketasalkar/Ecommerce-NotificationService)
   - Sends notifications to users regarding their orders and updates.
7. [PaymentService](https://github.com/aniketasalkar/Ecommerce-PaymentService)
   - Handles payment processing and transactions.
8. [InventoryService](https://github.com/aniketasalkar/Ecommerce-InventoryService)
   - Manages inventory levels and stock updates.
